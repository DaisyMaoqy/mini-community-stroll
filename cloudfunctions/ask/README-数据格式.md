# kb_chunks 数据格式（育儿问答知识库）

集合名：`kb_chunks`（云开发控制台 → 数据库 → 新建集合）

## 每条记录的字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `text` | string | ✅ | 知识片段正文（一段一个主题，别把整篇指南塞一条） |
| `question` | string | ✅ | 这段内容回答的是什么问题（口语化，用于后续假设性问题索引） |
| `topic` | string | ✅ | 主题标签：睡眠 / 喂养 / 辅食 / 大运动 / 健康 / 情绪… |
| `age_start` | number | ✅ | 适用月龄下限，不限填 `-1` |
| `age_end` | number | ✅ | 适用月龄上限，不限填 `-1` |
| `source` | string | ✅ | 来源：如 `卫健委0-6岁发育指南` / `社区UGC(匿名)` / `WHO` |
| `embedding` | number[] | ⏳ | 先空着，语料入库后用 tools/build_kb.js 批量生成写回 |

## 语料来源（两条腿）

1. **公开指南做底座**：卫健委《0-6 岁儿童发育行为评估量表》、WHO 育儿建议、儿保手册——切段时按主题+月龄拆，一段讲一件事
2. **真实提问做验证集**：妈妈群征集 + 小红书评论，目标 30 条——这部分**不直接进知识库**，而是留作评估表（30 题里 20 题应命中、10 题应拒答）

## 分块经验值（来自课程笔记 + 通用实践）

- 每段 200-500 字，带标题上下文
- 重叠不是必须的（问答场景按主题切即可，别过度工程）
- `question` 字段写得越口语，后续做假设性问题索引越省事
